# Add a Firebase Service

## Before You Start

1. Firebase must be initialized in `main.dart` via `Firebase.initializeApp()`.
2. Firebase options are in `lib/firebase_options.dart` (auto-generated by FlutterFire CLI).
3. Never hardcode API keys or secrets.

## 1. Add the package

// turbo
```
flutter pub add <firebase_package>
```

Common packages:
| Service | Package |
|---|---|
| Auth | `firebase_auth` |
| Firestore | `cloud_firestore` |
| Storage | `firebase_storage` |
| Crashlytics | `firebase_crashlytics` |
| Analytics | `firebase_analytics` |
| Performance | `firebase_performance` |
| Cloud Functions | `cloud_functions` |

## 2. Platform configuration

- **Android:** Ensure `google-services.json` is at `android/app/`.
- **iOS:** Ensure `GoogleService-Info.plist` is at `ios/Runner/`.
- Both files must come from the **same Firebase project** used by the Angular Web Dashboard.

## 3. Initialize in main.dart

```dart
void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await Firebase.initializeApp(
    options: DefaultFirebaseOptions.currentPlatform,
  );

  // Crashlytics (if added)
  FlutterError.onError = FirebaseCrashlytics.instance.recordFlutterFatalError;

  runApp(const MyApp());
}
```

## 4. Register in DI

Add to `lib/injection_container.dart` under the `// ! External` section:

```dart
// Firebase Auth
sl.registerLazySingleton(() => FirebaseAuth.instance);

// Firebase Storage
sl.registerLazySingleton(() => FirebaseStorage.instance);
```

## 5. Firestore-specific rules

- Enable offline persistence: `FirebaseFirestore.instance.settings = const Settings(persistenceEnabled: true);`
- Always construct full nested paths:
  ```
  /organizations/{orgId}/companies/{compId}/delegates/{uid}
  ```
- Use `FieldValue.serverTimestamp()` for time fields.
- Delegates can only read/write their **own** data.

## 6. Auth-specific rules

- Must read `/users/{uid}` first to retrieve `organizationUID` and `companyUID`.
- Then construct the path to the delegate document.
- Support phone and email sign-in methods.

## 7. Verify

```
flutter analyze
```
