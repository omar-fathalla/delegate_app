# ✨ ميزات نظام المقترحات والملاحظات

## 🎯 الميزات الأساسية

### 1. إرسال مقترحات متنوعة

يمكن للمستخدمين إرسال 5 أنواع من المقترحات:

| النوع | الأيقونة | الاستخدام | مثال |
|------|---------|----------|------|
| **فكرة تطويرية** | 💡 | اقتراح ميزة جديدة | "أريد إضافة خاصية التصدير إلى PDF" |
| **الإبلاغ عن مشكلة** | 🐛 | الإبلاغ عن خطأ أو مشكلة | "التطبيق يتوقف عند فتح الإعدادات" |
| **استفسار عام** | ❓ | سؤال أو استفسار | "كيف يمكنني تغيير كلمة المرور؟" |
| **تحسين** | ⭐ | تحسين ميزة موجودة | "يمكن جعل زر الحفظ أكبر" |
| **أخرى** | 📝 | أي نوع آخر | "شكراً على التطبيق الرائع" |

### 2. إرفاق صور (اختياري)

- ✅ اختيار صورة من المعرض
- ✅ معاينة الصورة قبل الإرسال
- ✅ حذف الصورة بسهولة
- ✅ رفع آمن إلى Firebase Storage
- ✅ حد أقصى 5MB
- ✅ صيغ الصور فقط (jpg, png, etc.)

**فائدة:** مفيد جداً عند الإبلاغ عن مشكلة تقنية

### 3. تتبع حالة المقترح

كل مقترح له حالة واضحة مع لون مميز:

| الحالة | اللون | الأيقونة | الوصف |
|-------|------|---------|-------|
| **قيد المراجعة** | 🟠 برتقالي | ⏳ | تم استلام المقترح وسيتم مراجعته قريباً |
| **تمت المراجعة** | 🔵 أزرق | 👀 | تمت مراجعة المقترح من قبل الفريق |
| **قيد التنفيذ** | 🟣 بنفسجي | 🔨 | جاري العمل على تنفيذ المقترح |
| **تم الحل** | 🟢 أخضر | ✅ | تم تنفيذ المقترح أو حل المشكلة |
| **مرفوض** | 🔴 أحمر | ❌ | تم رفض المقترح مع توضيح السبب |

### 4. ردود الإدارة

- ✅ يمكن للمسؤولين إضافة رد على أي مقترح
- ✅ يظهر الرد في صندوق مميز
- ✅ أيقونة خاصة للردود الإدارية
- ✅ يساعد المستخدم على فهم قرار الإدارة

**مثال:**
```
👤 رد الإدارة:
شكراً على اقتراحك! سنعمل على إضافة هذه الميزة في التحديث القادم.
```

### 5. عرض المقترحات السابقة

- ✅ قائمة بجميع المقترحات
- ✅ ترتيب من الأحدث للأقدم
- ✅ عرض النوع مع أيقونة
- ✅ عرض الحالة مع لون
- ✅ عرض المحتوى (3 أسطر)
- ✅ عرض الصورة إن وجدت
- ✅ عرض رد الإدارة إن وجد
- ✅ عرض التاريخ والوقت
- ✅ Pull to Refresh للتحديث

## 🎨 تجربة المستخدم (UX)

### صفحة إرسال مقترح

#### 1. رسالة ترحيبية
```
💡 نحن نقدّر رأيك! ساعدنا في تحسين تجربتك
```

#### 2. اختيار النوع (Choice Chips)
- تصميم جميل وسهل الاستخدام
- ألوان مميزة للاختيار النشط
- أيقونات معبرة لكل نوع

#### 3. حقل النص
- 8 أسطر للكتابة المريحة
- عداد الأحرف (1000 حرف كحد أقصى)
- نص توضيحي: "أخبرنا كيف يمكننا تحسين تجربتك..."
- التحقق من الحد الأدنى (10 أحرف)

#### 4. إرفاق صورة
- زر واضح مع أيقونة
- معاينة الصورة بعد الاختيار
- زر حذف في الزاوية
- رسالة خطأ إذا كان الحجم كبير

#### 5. زر الإرسال
- زر كبير وبارز
- أيقونة إرسال
- نص واضح: "إرسال المقترح"
- يتحول إلى مؤشر تحميل عند الإرسال

#### 6. رسالة النجاح
- Dialog جميل
- أيقونة ✓ خضراء كبيرة
- رسالة شكر
- زر "حسناً" للإغلاق
- يعود تلقائياً للصفحة السابقة

### صفحة مقترحاتي

#### 1. قائمة المقترحات
- Cards جميلة لكل مقترح
- تباعد مناسب
- ظلال خفيفة
- حواف دائرية

#### 2. محتوى كل Card
```
┌─────────────────────────────────────┐
│ 💡 فكرة تطويرية    [🟠 قيد المراجعة] │
│                                     │
│ محتوى المقترح هنا...               │
│                                     │
│ [صورة إن وجدت]                     │
│                                     │
│ ┌─────────────────────────────────┐ │
│ │ 👤 رد الإدارة:                  │ │
│ │ شكراً على اقتراحك...            │ │
│ └─────────────────────────────────┘ │
│                                     │
│ 🕐 01/04/2026 - 14:30              │
└─────────────────────────────────────┘
```

#### 3. حالات خاصة
- رسالة عند عدم وجود مقترحات
- أيقونة كبيرة
- نص تشجيعي: "ابدأ بإرسال مقترحك الأول!"

#### 4. Pull to Refresh
- اسحب للأسفل للتحديث
- مؤشر تحميل أثناء التحديث
- تحديث تلقائي للقائمة

## 🎯 حالات الاستخدام

### 1. مستخدم يريد اقتراح ميزة جديدة
```
1. يفتح الإعدادات
2. يضغط "إرسال مقترح"
3. يختار "💡 فكرة تطويرية"
4. يكتب اقتراحه
5. يضغط "إرسال"
6. يرى رسالة نجاح
```

### 2. مستخدم يواجه مشكلة تقنية
```
1. يفتح الإعدادات
2. يضغط "إرسال مقترح"
3. يختار "🐛 الإبلاغ عن مشكلة"
4. يكتب وصف المشكلة
5. يرفق لقطة شاشة
6. يضغط "إرسال"
7. يرى رسالة نجاح
```

### 3. مستخدم يريد متابعة مقترحاته
```
1. يفتح الإعدادات
2. يضغط "مقترحاتي"
3. يرى قائمة بجميع مقترحاته
4. يتحقق من الحالة
5. يقرأ رد الإدارة إن وجد
```

### 4. مسؤول يريد الرد على مقترح
```
1. يفتح Firebase Console
2. يذهب إلى Firestore > feedbacks
3. يفتح المقترح
4. يعدّل حقل "status"
5. يضيف "adminResponse"
6. يحفظ التغييرات
7. المستخدم يرى التحديث فوراً
```
